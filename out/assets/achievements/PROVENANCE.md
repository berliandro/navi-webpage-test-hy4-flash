# Achievement icon provenance

The first VectorCraft set was **removed** at the user's direction: its drawing
quality sat below this site's standard. These four replacements are sourced
icon glyphs, recoloured into the Cut-and-Sew visual system and self-hosted here.
No image model was used.

## Changes made to the source glyphs

- Replaced the monochrome fill with a **NAVI-thread halftone** pattern
  (`#ffd400` ground, `#14150f` dots on a 45° 14px screen) — the same dot-screen
  language the retired set used, now applied consistently to all four.
- Added a **16px ink outline** (`#14150f`, round joins) on the 512-unit viewBox.
- Kept the source path geometry, viewBox and single-glyph composition intact.
- The hard block shadow is applied in CSS on `.crest-badge`
  (`drop-shadow(10px 12px 0 #14150f)`), so it does not alter the vector file.
